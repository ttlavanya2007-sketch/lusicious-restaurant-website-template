IMPORTANT FOR SELLING

Before selling, replace them with images you have permission to distribute, or package properly licensed/local assets in an assets folder.
Replace restaurant name, address, social links and text with your own template copy.


REVIEW NOTE
Reviews entered by a visitor are saved in that browser using localStorage, so they remain after refresh on the same browser/device. A shared multi-user review system requires a backend/database such as Supabase.
